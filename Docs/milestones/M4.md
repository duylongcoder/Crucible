## Save

File `Application.persistentDataPath/run.json`, ghi sau mỗi Command được chấp nhận:
`{ version, runDefId, seed, actions[], snapshotAt, snapshot }`. Snapshot chụp ở đầu mỗi lượt (Chiếu chỉ, Chợ của lượt kế).
Khi mở lại: khôi phục snapshot rồi replay `actions[snapshotAt..]`. Run kết thúc thì xóa save. Save sai version / RunDef / hỏng: bỏ qua, bắt đầu run mới.
Standalone ghi file tạm rồi `File.Replace`; WebGL ghi thẳng rồi gọi `JS_FileSystem_Sync` (flush IndexedDB).
