# M6 – GreedyAgent, fuzz, báo cáo cân bằng

Tiêu chí xong: 50.000 run nightly sạch bất biến. Không có thay đổi scene.

## Harness

| Agent | Ở đâu | Chạy |
| --- | --- | --- |
| RandomAgent | `RandomAgentTests` | xoay vòng 3 bậc khó × 3 bộ khởi đầu, mở hết khóa; 1.000 run/commit, 50.000 nightly |
| GarbageAgent (fuzz index rác, null) | `RandomAgentTests` | 1.000 run/commit, 50.000 nightly |
| GreedyAgent | `GreedyAgent` + `BalanceReportTests` | 300 run mỗi bậc khó/commit, 50.000 nightly; ghi `results/balance-report.md` |

Số run lấy từ `-harnessRuns N` trên dòng lệnh Unity (`Harness.Runs`). Nightly: `.github/workflows/nightly-harness.yml` (02:00 giờ VN, có `workflow_dispatch`).
Kiểm cục bộ trong Editor: 10.000 run RandomAgent + 9.000 run GreedyAgent (mọi bậc khó, bộ khởi đầu), 0 run kẹt, 0 vi phạm bất biến.

GreedyAgent biết mọi công thức kể cả khoảng cách, nhìn Quality và Power đối thủ, dâng thành phẩm yếu nhất vẫn thắng, giữ 2 thành phẩm, bán thứ thừa. Đây là cận trên của người chơi đã tra công thức; người mới sẽ yếu hơn.
