## Object → script + component

| Object | Script (Alchemy.Presentation) | Component Unity | Field serialized đã gán |
| --- | --- | --- | --- |
| `Canvas` | `BootView` (M0) | Canvas, CanvasScaler, GraphicRaycaster | `_buildLabel` → BuildLabel |
| `Canvas/Game` | `GameController` | RectTransform | `_views` → [Hud, Bag, Decree, Market, Furnace, Workshop, Battle, Spoils, End]; `_toast` → Toast; `_dragGhost`, `_dragGhostLabel` → DragGhost |
| `Game/Background` | — | Image (raycast tắt) | — |
| `Game/Hud` | `HudView` | Image | `Game`; `_info` → Info; `_modifier` → Modifier |
| `Game/Bag` | `BagView`, `DropZone` | Image (raycast bật, nhận thả để gỡ khỏi lưới) | BagView: `Game`; `_title`; `_items` → Items; `_dropZone` → Bag; `_detail`; `_actions` → Actions. DropZone: `_game` → Game |
| `Bag/Items`, `Bag/Actions`, `Market/Offers`, `Spoils/Choices` | `ButtonList` | — (Container có GridLayoutGroup) | `_template` → Template; `_container` → Container |
| `…/Template`, `Furnace/Grid/Cell0..8` | `ItemButton` | Image, Button; con `Label` có Text | `_button`, `_label`, `_background`; `_game` → Game (clone từ Template giữ nguyên reference) |
| `Stage/Decree` | `DecreeView` | Image | `Game`; `_title`, `_body`, `_continue` |
| `Stage/Market` | `MarketView` | Image | `Game`; `_title`, `_offers`, `_reroll`, `_rerollLabel` (Text con của Reroll), `_toFurnace`, `_skip` |
| `Stage/Furnace` | `FurnaceView` | Image | `Game`; `_cells` → Cell0..8; `_brew`, `_skip`, `_continue`; `_speeds` → Speed1..3; `_status`, `_log`; `_brewTickSeconds` = 3 |
| `Stage/Workshop` | `WorkshopView` | Image | `Game`; `_title`, `_body`, `_continue` |
| `Stage/Battle` | `BattleView` | Image | `Game`; `_lines`, `_verdict`, `_continue`; `_stepSeconds` = 0.9 |
| `Stage/Spoils` | `SpoilsView` | Image | `Game`; `_choices` → Choices |
| `Stage/End` | `EndView` | Image | `Game`; `_title`, `_summary`, `_newRun` |
| Các nút (`Continue`, `Brew`, `Skip`, `Reroll`, `ToFurnace`, `NewRun`, `Speed1..3`) | — | Image, Button; con `Label` có Text | listener gắn trong `OnViewAwake` của view cha |
| `Game/Toast` | — | Text | — |
| `Game/DragGhost` | — | Image (raycast tắt); con `Label` Text | — |
| `EventSystem` | — | EventSystem, InputSystemUIInputModule | — (Player Settings: Input System only) |

Script không gắn object: `GameView` (base của mọi view), `ViewBehaviour` (M0, kiểm reference bắt buộc ở `Awake`), `UiText` (chuỗi + màu greybox).

## Luồng dữ liệu

`View` → `GameController.Send(ICommand)` → `RunStateMachine.Execute` → nếu nhận: `RefreshAll()` gọi `GameView.Refresh(RunState)` cho mọi view; nếu từ chối: Toast. Không có `Update`/`FixedUpdate` và không `GetComponent`/`Find` lúc chạy: view chỉ vẽ lại khi `RefreshAll()`, kéo thả đọc `GameController.Dragging`, animation dùng coroutine `WaitForSeconds`. Presentation chỉ đọc API public của Core; thuộc tính ẩn, `Power`, khoảng cách công thức là `internal` nên không đọc được.
