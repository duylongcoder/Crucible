# M5 – Seed, Danh vọng, Sổ công thức, bậc khó, bộ khởi đầu

Tiêu chí xong: cùng seed trên Editor, Standalone và WebGL cho cùng Chợ đầu, cùng giá Mùa 1, cùng loại trang bị rèn ở Mùa 1.
Mockup: [`Docs/ui/M5-mockup.html`](../ui/M5-mockup.html) (vẽ trước khi dựng scene).

## Luật đã cài

| Hệ thống | Luật |
| --- | --- |
| Bậc khó | 3 bậc (`DifficultyDef`), mỗi bậc 8 đối thủ riêng + hệ số Danh vọng 100 / 150 / 200%. Bậc đầu mở sẵn; thắng run ở bậc i mở bậc i + 1 |
| Danh vọng | Cuối run (thắng hay trục xuất): (Thắng × 10 + tier cao nhất đã nung × 5 + thắng run ? 30) × hệ số bậc khó. Số liệu trong `MvpRun.asset` |
| Mở khóa theo mốc | Tự mở khi Danh vọng tích lũy đạt mốc: Thợ đúc đồng 40, Lò đôi vào Chợ 80, Quặng vàng vào Chợ 100, Nhà luyện kim 120, Búa thợ cả vào bể chiến lợi phẩm 150 |
| Mở khóa theo khoáng | Nung ra → `ItemUnlocked` + `RecipeUnlocked`; mua / nhận / bộ khởi đầu / CreateIngredient → chỉ `ItemUnlocked`. Gộp vào meta khi run kết thúc |
| Sổ công thức | `RecipeBook`: nguyên liệu + thứ tự của công thức đã mở (meta hoặc vừa nung trong run). Không có khoảng cách, phụ gia, RequiresMagic, thuộc tính. Nút Sổ khóa trong `Brewing` (không lộ kết quả sớm) |
| Seed | Ô nhập: số → chính số đó; chữ → FNV-1a của chuỗi; trống → ngẫu nhiên. HUD bản debug hiện `seed · hash` để so tất định |
| Lưu | `run.json` v2 thêm `difficulty`, `starterKit`, `renown`; snapshot thêm tier cao nhất, danh sách đã nung / đã nhận. `meta.json` riêng, ghi trước khi xóa save run |

## Hierarchy (đổi so với M3)

```
Canvas/Game
├── Hud
│   ├── Info, Modifier         (Info thêm tên bậc khó; Modifier thêm hash ở bản debug)
│   └── Book                   mới: nút "Sổ công thức" (khóa trong Brewing)
├── …                          (Bag, Stage/* như M3)
├── RecipeBook                 mới, (inactive) overlay; bật khi bấm Hud/Book
│   └── Panel → Title, Body, Close
├── Setup                      mới, (inactive) phủ toàn màn; bật khi không có run dở và sau End/NewRun
│   ├── Title, Renown, DifficultyTitle, KitTitle, SeedTitle
│   ├── Difficulties           ButtonList → Container, Template
│   ├── Kits                   ButtonList → Container, Template
│   ├── Seed                   InputField → Text, Placeholder
│   └── Start
├── Toast, DragGhost
```

## Object → script + component (dòng mới / đổi)

| Object | Script | Field serialized đã gán |
| --- | --- | --- |
| `Canvas/Game` | `GameController` | thêm `_setup` → Setup, `_book` → RecipeBook |
| `Game/Hud` | `HudView` | thêm `_book` → Hud/Book |
| `Game/RecipeBook` | `RecipeBookView` | `_game` → Game; `_body` → Panel/Body; `_close` → Panel/Close |
| `Game/Setup` | `SetupView` | `_game` → Game; `_renown` → Renown; `_difficulties` → Difficulties; `_kits` → Kits; `_seed` → Seed (InputField); `_start` → Start |
| `Setup/Seed` | — | Image, InputField (`textComponent` → Text, `placeholder` → Placeholder, giới hạn 40 ký tự) |
| `Stage/End` | `EndView` | như M3; NewRun giờ mở Setup; Summary thêm Danh vọng + mở khóa |
